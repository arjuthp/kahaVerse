================================================================================

MANUAL METHOD:
--------------

1. Login to production:
   
   curl -X POST https://api.kaha.com/v3/auth/login \
     -H "Content-Type: application/json" \
     -d '{"email": "your-email@example.com", "password": "your-password"}'

2. Copy from response:
   
   user.id          → userId
   user.businessId  → businessId
   accessToken      → authToken

3. Update Postman variables:
   
   - Open collection in Postman
   - Go to Variables tab
   - Update userId, businessId, authToken
   - Save

4. Test!

VERIFICATION:
-------------

1. Check variables updated:
   - Open collection → Variables tab
   - Verify userId/businessId are real UUIDs

2. Test public endpoint:
   GET http://127.0.0.1:3001/api/v1/categories/business/{{businessId}}

3. Test admin endpoint:
   POST http://127.0.0.1:3001/api/v1/categories
   (Should return 201, not 401/500)

================================================================================

TROUBLESHOOTING:
----------------

❌ "User not found"
   → Re-run script or login again to get correct user ID

❌ "Business not found"
   → Use businessId from login response

❌ "Insufficient permissions" (403)
   → User needs BUSINESS_SUPER_ADMIN role for admin endpoints

❌ "Unauthorized" (401)
   → Token expired, re-run script to get fresh token

❌ Script connection error
   → Check if production API is accessible
   → Try: curl https://api.kaha.com/v3/health
