# KAHA — Changes To Make

- Add percentage-based discount on vouchers (currently only fixed NPR amount)
  - Research standard tiers: small orders ~5%, mid orders ~10%, large orders up to 25% max cap
  - Discount applies on subtotal only, not on tax/fees

- Loyalty points and vouchers are two separate things
  - Business/admin controls when and how points are awarded (not automatic)
  - Points given per event, per specific menu item ordered, or when customer crosses an order count milestone
  - Customer redeems accumulated points to get voucher codes
  - Vouchers are generated by the system — customers cannot create them directly

- Split customer "My Orders" into two sections
  - Active orders (pending, processing, shipped)
  - Order history (delivered, cancelled)

- Menu items with active orders cannot be deleted
  - Admin can hide the item (remove from customer view) instead
  - Admin can mark it as out of stock instead
  - Deletion only allowed when no pending/processing/shipped orders reference that item

- Loyalty points settings should support percentage modes
  - Points per visit (once per day per customer)
  - Points as a percentage of transaction value

- Add pagination to the Users Overview section in admin panel

- Add table management for dine-in orders
  - Admin defines tables (number, capacity, section)
  - Customer selects a table when choosing dine-in at checkout
