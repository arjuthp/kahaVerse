# KAHA — Changes & Status

## ✅ DONE

- **Percentage-based discount on vouchers**
  - Fixed-amount and percentage vouchers both supported
  - Discount applies on subtotal only, not on tax/fees

- **Loyalty points and vouchers — two separate systems**
  - Admin controls when/how points are awarded (not automatic)
  - Points per event, per menu item, or per milestone order count
  - Customer redeems accumulated points to get voucher codes
  - Vouchers generated by the system — customers cannot create directly

- **Split customer "My Orders" into two sections**
  - Active orders tab: pending, processing, shipped
  - Order history tab: delivered, cancelled

- **Menu items with active orders cannot be deleted**
  - Admin can hide the item (remove from customer view) instead
  - Admin can mark it as out of stock
  - Deletion only allowed when no pending/processing/shipped orders reference the item

- **Loyalty points settings — percentage modes**
  - Points per visit (once per day per customer)
  - Points as a percentage of transaction value

- **Add pagination to Users Overview in admin panel**

- **Table management for dine-in orders**
  - Admin defines tables (number, capacity, section) via `/api/admin/tables`
  - Customer selects a table when choosing dine-in at checkout
  - `RestaurantTableEntity` created with fields: businessId, tableNumber, capacity, section, status, isActive, notes
  - Sections supported: indoor, outdoor, rooftop, bar, private
